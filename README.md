# 커뮤니티 나침반

회식 자리에서 9개의 예·아니오 카드를 넘기며 `관계의 기준 · 결정의 방식 · 자원의 기준`을 발견하는 모바일 우선 웹사이트입니다.

## 기능

- 닉네임만 입력하고 시작
- 카드 스와이프(왼쪽 아니오, 오른쪽 예) 및 버튼 선택
- 3개 키워드와 8가지 역할 조합 결과
- 9개 질문의 내 선택과 각 선택이 뜻하는 키워드를 다시 보는 결과 상세 화면
- Web Share API 및 클립보드 복사 공유
- 서버 없이 브라우저에 결과만 저장

## GitHub Pages 배포

`dist/` 폴더의 내용을 저장소 루트 또는 `docs/` 폴더에 두고 GitHub Pages의 배포 소스로 지정하면 됩니다.

## 로컬 미리보기

```bash
cd dist
python3 -m http.server 4173
```
